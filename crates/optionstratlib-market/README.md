# optionstratlib-market

Market data of [OptionStratLib](https://github.com/joaquinbejar/OptionStratLib):
option chains and option series, their build parameters, parsing, and CSV,
JSON and ZIP readers and writers, and, under `synthetic`, chains and series
generated by a random walk. The crate depends on `optionstratlib-core`,
`optionstratlib-math` and `optionstratlib-pricing`, on
`optionstratlib-simulation` only under `synthetic`, and on no analytics,
strategy, backtesting or plotting code.

| Module   | Contents                                                                  |
|----------|---------------------------------------------------------------------------|
| `chains` | `OptionChain`, `OptionData`, build parameters, strategy-leg lookups, OHLCV readers |
| `series` | `OptionSeries` across expirations and its build parameters                |
| `error`  | `ChainError`, `OhlcvError`                                                |

Analyses over a chain (risk-neutral density, projections, metrics) are
analytics, in `optionstratlib-analytics`.

## Features

| Feature  | Default | Effect                                                               |
|----------|---------|----------------------------------------------------------------------|
| `io`     | no      | CSV/JSON chain files and the OHLCV ZIP reader; adds `csv` and `zip`   |
| `async`  | no      | `tokio`-backed `*_async` wrappers on `spawn_blocking`; implies `io`   |
| `synthetic` | no   | `generator_optionchain` / `generator_optionseries`; adds `optionstratlib-simulation` |
| `schema` | no      | Derives `utoipa::ToSchema` on market types and enables `schema` below |
